# 教程 00：图像、框、类别与批次

[English](00-basics.md) | [教程索引](README.zh-CN.md)

这一章建立后续数据、模型、训练和评估都会使用的张量规则。只需要会看基本 Python 索引和
张量形状，不需要 VOC 数据、检查点或网络。

## 一张图像对应一个标注字典

检测样本由图像与标注组成，而不是单个张量：

```text
image                       float32 [3, H, W]，值域 [0, 1]
target["boxes"]             float32 [N, 4]
target["labels"]            int64   [N]
target["image_id"]          int64   [1]
target["area"]              float32 [N]
target["iscrowd"]           int64   [N]
target["difficult"]         bool    [N]
```

所有逐目标字段的第一维都必须是同一个 `N`。`N` 可以为零；空标注的 `boxes` 仍必须是
`[0,4]`，不能是 `[0]`，其余逐目标字段则是 `[0]`。`difficult` 是 VOC 标注中的字面字段
名，用来标记困难目标。图像可能原本没有目标，也可能只含困难目标，而困难目标会在训练时
被移除，所以空标注是正常规则的一部分。

标签是类别索引，不是任意编号。torchvision 把 `0` 保留给背景，本项目将 20 个 VOC 前景
类别映射到 `1..20`。背景来自没有匹配前景标注的候选区域，不要人为创建标签为 `0` 的
“背景框”。

## 手算一个 xyxy 框

项目统一使用零基连续 `xyxy` 坐标：

```text
[x1, y1, x2, y2] = [左, 上, 右, 下]
width  = x2 - x1
height = y2 - y1
area   = width * height
```

示例中的第一个框 `[2,3,18,15]` 宽为 `18-2=16`，高为 `15-3=12`，面积为 `192`。
第二个框 `[20,4,30,22]` 的面积是 `(30-20)*(22-4)=180`。

运行实际计算：

```bash
uv run python examples/01_boxes_and_labels.py
```

预期输出包含两个框、`labels=[1, 3]` 和 `areas=[192.0, 180.0]`。先改一个坐标并在纸上
算出新面积，再运行核对。若 `x2 <= x1` 或 `y2 <= y1`，这个框就无效。

## 为什么检测批次要用两个列表

分类示例常把图像堆成 `[B,3,H,W]`。检测图像进入模型前保留各自尺寸，`[3,16,20]` 与
`[3,12,24]` 无法直接堆叠；每张图的目标数也不同。因此批次整理函数返回：

```text
images  = list[Tensor[3, Hi, Wi]]
targets = list[dict[str, Tensor]]
len(images) == len(targets) == batch size
```

运行项目真实的 `detection_collate`：

```bash
uv run python examples/02_detection_batch.py
```

预期输出为：

```text
image_shapes=[(3, 16, 20), (3, 12, 24)]
target_counts=[1, 2]
```

torchvision 收到列表后才在模型内部缩放、归一化和填充，并保留原图尺寸信息，以便把最终
框映射回图像坐标。不要在外部强行堆叠不同尺寸图像，也不要添加一套无法恢复原始尺寸的
自定义填充方法。

## IoU 是重叠程度，不是置信度

框 `A=[10,10,30,30]` 与 `B=[20,10,40,30]` 的面积都为 `400`，交集为 `10*20=200`，
并集为 `400+400-200=600`，所以 IoU 为 `1/3`。模型分数回答的是置信度问题，不能代替
IoU。第 05 章会分别使用这两类阈值。

## 常见错误

- `boxes` 是整数、最后一维不是 4，或宽高非正：数据或模型会在有效学习前失败。
- `labels` 是浮点数或把目标标成背景 `0`：即使形状正确，类别规则也已经损坏。
- 整理批次前先堆叠图像：不同尺寸无法组成一个矩形张量。
- 用 `torch.tensor([])` 表示空框：得到的是 `[0]`，需要显式 `reshape` 为 `[0,4]`。
- 面积公式仍使用端点包含坐标的 `+1`：项目已经转换到连续边界，不能再加 1。
