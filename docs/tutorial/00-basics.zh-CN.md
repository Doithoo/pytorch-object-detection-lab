# 00 - 检测基础

分类为整张图分配一个标签；检测则要为每个目标回答“是什么”和“在哪里”。每个输入是 `[3,H,W]` RGB 浮点张量，target 包含 `boxes: float32[N,4]` 和 `labels: int64[N]`。

框 `[10,20,50,70]` 采用 `xyxy`，依次是左、上、右、下；宽为 `40`，高为 `50`，面积为 `2000`。本项目使用从零开始的连续坐标，右边界和下边界不包含在框内。

同一 batch 的图像尺寸与目标数可以不同，因此 torchvision 检测器接收列表而非堆叠张量。空 target 仍应使用 `[0,4]` 和 `[0]` 形状的张量。练习：修改一个示例框，手算面积并核对输出。

运行：`uv run python examples/02_detection_batch.py`

预期：输出两个不同图像尺寸，以及目标数 `1` 和 `2`。
