# Pascal VOC 2007 协议

[English](voc2007.md) | [数据集契约](dataset-format.zh-CN.md)

本页帮助需要区分官方 Pascal VOC 2007 协议和兼容夹具的用户，记录仓库实现的源文件标识与划分规则，但不发布检测器结果。

## 官方压缩包

| 压缩包 | URL 文件名 | 发布的 MD5 |
|---|---|---|
| 训练/验证 | `VOCtrainval_06-Nov-2007.tar` | `c52e279531787c972589f7e41ab4ae64` |
| 测试 | `VOCtest_06-Nov-2007.tar` | `b6e924de25625d8de591ea690078ad9f` |

```bash
uv run python scripts/download_data.py --data-dir data/raw
```

下载器把压缩包保存到 `data/raw/archives`，只有现有文件 MD5 匹配时才复用。下载先写入 `.part`，校验后才替换，失败时删除临时文件。解压会拒绝绝对路径、目录穿越、链接和既非文件也非目录的成员。若已解压文件内容冲突，命令会失败而不是覆盖。

## 官方划分契约

| 运行时划分 | VOC 文件 | 必须的图像数 |
|---|---|---:|
| `train` | `ImageSets/Main/train.txt` | 2501 |
| `valid` | `ImageSets/Main/val.txt` | 2510 |
| `test` | `ImageSets/Main/test.txt` | 4952 |

```bash
uv run detect prepare-data --data-dir data/raw --manifest-dir data/manifests
```

准备阶段要求准确数量、各划分内部标识唯一，且任意两个划分之间没有重叠。随后校验每个 JPEG/XML 对，并原子发布根据内容生成的清单。成功输出会打印一个标识和三个划分数量。

`--allow-nonstandard-counts` 只移除三项数量要求，不会放宽划分互斥、文件配对、XML 结构、支持类别、坐标有效性、图像解码、文件名匹配或尺寸匹配。它适合确定性测试和有意构造的 VOC 形状数据，不能用来掩盖不完整的官方下载。

## 困难目标与测试纪律

VOC `difficult=1` 目标不会进入训练和普通目标计数，但会以 `iscrowd=1` 保留用于评估和证据。AP/AR 使用 torchmetrics `MeanAveragePrecision` 的 COCO 风格后端，因此项目不宣称与历史 VOC 评估程序逐位一致。评估产物会记录后端版本与阈值。

train 用于优化，valid 用于检查点和超参数选择。所有选择固定后才评估 test。包含样本上限、修改划分、非标准数量或修改类别的运行，不是完整官方协议结果。

[参考实测运行](../recorded-run/README.zh-CN.md)已经满足这项证据边界，并为一个由验证集选择的 checkpoint 报告测试 `map_50_95 = 0.322312`。其中包含清单标识、划分哈希、解析配置、checkpoint 哈希、后端版本、耗时和最终产物。单独配方或另一次未记录执行仍不属于同等级证据。
